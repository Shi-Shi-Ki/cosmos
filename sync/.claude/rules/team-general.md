# チーム共通

- ライブラリやフレームワークの API を使う前に、CLAUDE.md に書かれたバージョンのドキュメントを確認する。確認できなかった場合は推測であることを明記する
- 設計判断（ライブラリ選定、データモデル変更、アーキテクチャ変更）は実装前に 2〜3 個の選択肢とトレードオフを示す。決定は人間が行う
- 秘密情報（API キー、トークン、パスワード）をコード、ログ、テストデータ、コミットメッセージに書かない
- 外部入力（HTTP リクエスト、スプレッドシートの値、環境変数、ファイル）は信頼せず、使う直前に検証する
- 失敗したテストを削除・スキップして通すことはしない
